## ClipFX Enhance 1.1.0

**Now on Windows, macOS and Linux.**

| | Download |
|---|---|
| Windows 10/11 (x64) | `ClipFX-Enhance-windows-x64-setup.exe` |
| macOS 11+ (Apple Silicon and Intel) | `ClipFX-Enhance-macos-universal.dmg` |
| Linux (Debian/Ubuntu) | `clipfx-enhance-linux-amd64.deb` |
| Linux (Fedora/openSUSE) | `clipfx-enhance-linux-x86_64.rpm` |
| Linux (any distribution) | `ClipFX-Enhance-linux-x86_64.AppImage` |

### New
- **GPU acceleration on any graphics card**: NVIDIA, AMD, Intel and Apple, through Vulkan, DirectX 12 and Metal.
- **Uses your whole computer by default**: all CPU threads but one, nearly all memory, and big GPU tiles.
- **In-app updates**: a bar tells you when a new version is out. On Windows, only the app is downloaded (about 8 MB), not the whole installer. Every update is signature-checked.
- **macOS app** with FFmpeg built in, including stabilization and HDR.
- The Models page shows the recommended hardware for each model.

### Fixed
- With the FFmpeg bundled on Windows, the app could not see any filters, so stabilization and HDR conversion were unavailable.
- Exports made with newer FFmpeg lost their colour primaries and transfer tags, so some players could show the colours wrong.
- HDR conversion of untagged video failed with newer FFmpeg.
- A job could briefly show as finished before its report was saved.

### Notes
- **macOS**: the app is not notarized by Apple (that requires a paid developer account), so macOS asks before the first launch. Drag it to Applications and open it once. Then go to System Settings → Privacy & Security, click **Open Anyway**, and confirm.
- **Linux**: the `.deb` and `.rpm` install FFmpeg from your distribution. The AppImage needs `ffmpeg` installed.
