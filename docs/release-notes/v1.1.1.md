## ClipFX Enhance 1.1.1

### Fixed
- **Linux**: on some systems (certain NVIDIA drivers, virtual machines, remote and virtual displays) the window opened blank. The app now uses the WebKitGTK renderer that always works.

Windows and Linux (.deb) users of 1.1.0 get this through the update bar in the app; the Windows update is about 8 MB. On macOS, the AppImage and the .rpm, download the new version from this page.

| | Download |
|---|---|
| Windows 10/11 (x64) | `ClipFX-Enhance-windows-x64-setup.exe` |
| macOS 11+ (Apple Silicon and Intel) | `ClipFX-Enhance-macos-universal.dmg` |
| Linux (Debian/Ubuntu) | `clipfx-enhance-linux-amd64.deb` |
| Linux (Fedora/openSUSE) | `clipfx-enhance-linux-x86_64.rpm` |
| Linux (any distribution) | `ClipFX-Enhance-linux-x86_64.AppImage` |
